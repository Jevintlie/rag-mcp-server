# Security policy

Please report suspected vulnerabilities privately to the repository owner instead of opening a public issue with exploit details.

Do not commit API keys, private MCP client configuration, downloaded source pages, vector databases, or model caches. The repository includes `.env.example` and `mcp_servers.example.json` only as non-secret templates.

Programme information returned by this project must be treated as advisory. Production clients should show the stored source URL and freshness date and direct users to the official university page for decisions involving fees, admissions, or programme requirements.
